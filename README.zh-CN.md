# Imprint

**为你的下一个项目，设计名称、Logo 与应用图标。**

Imprint 是面向独立应用开发者和创意者的设计 skill。为你的应用设计图标、为新产品起名，也能为公司或工作室设计 Logo。从比较方向到精修和文件交付，你可以只做其中一项，也可以组合完成。

## 快速开始

使用能加载 skill、创建文件的 agent。视觉任务还需要相应的图像生成或矢量编辑工具。

在已安装 Node.js 和 npm 的终端中运行：

```bash
npx skills add Frost-96/imprint
```

按提示选择 agent 和安装位置。也可以将整个 [`skills/imprint/`](skills/imprint/) 文件夹（包括 references）复制到你的 agent 的 skills 目录。

然后从你需要的部分开始：

**为自己的应用设计图标**

> 使用 Imprint，为我正在开发的 iOS 专注计时器设计应用图标。希望它温暖、有趣，在主屏幕上容易辨认。先给我几个有明显区别的方向，再精修我选中的方案，附上小尺寸预览和图标导出文件。

**设计名称与 Logo**

> 使用 Imprint，为一个帮助独立声音设计师整理田野录音的桌面工具起名并设计 Logo。希望它精确、务实，有一点个性。先给出命名方向，再帮我比较视觉方案。

Imprint 会补齐影响设计的关键信息，提供候选与取舍；你选择方向后，再继续精修和准备文件。最终名称和视觉版本由你选定，也可以明确委托 agent 代选。有参考图或已有品牌资产时，一并附上。

## 为什么使用 Imprint

- **为应用设计有辨识度的图标。** 从主体、轮廓、配色到材质，探索适合应用的方向，再检查缩小后以及主屏幕或 Dock 中的表现。[了解图标设计流程](#为独立开发者设计应用图标)。
- **选择名称和 Logo，也理解取舍。** 命名候选和 Logo 方向附带各自的优势与代价，帮助你作出选择。[看看 Notch 的命名候选](examples/notch/README.zh-CN.md#为想法命名)。
- **从你需要的部分开始。** 名称、Logo、应用图标可以单独或组合设计。已有名称和资产会保留，除非你要求修改。[找到适合你的提示词](#更多用法)。
- **把设计带进项目。** 获得图标母版和所需尺寸版本，或可编辑的 Logo 源文件与导出，并附上预览和使用说明。[查看交付内容](#你会得到什么)。

## 为独立开发者设计应用图标

正在开发第一个应用、准备发布，或想更新已有图标？从应用用途、目标用户和运行平台开始即可。你可以只设计图标，也可以一起完成应用名称与图标，无需先准备 Logo。

| 阶段 | 一起完成什么 |
| --- | --- |
| 探索方向 | 根据应用特点和参考图，比较角色、扁平图形、插画、立体材质或像素等风格的方案 |
| 放进场景精修 | 调整轮廓、配色、细节和视觉分量，检查小尺寸以及目标平台的主屏幕、Dock 或启动器预览 |
| 准备应用资产 | 提供高分辨率母版、源文件、PNG 导出和所需尺寸版本；需要原生平台图标包时可一并说明 |

你可以带上应用截图、现有图标或喜欢的风格参考。[浏览 24 个应用图标示例](examples/icons/wall.webp)，或[查看单个图标](examples/icons/cases/)。

## 从需求到品牌形象

**Notch：一个虚构的田野录音管理工具。** 需求是设计英文名称和 Logo，帮助声音设计师从录音素材中找回有用的片段。

| 探索的名称 | 设计理由 | 取舍 |
| --- | --- | --- |
| **Notch** · 选定 | 简短，与标记一个位置的动作相关 | 可能让人先联想到音频滤波器 |
| Set Aside | 用自然短语表达保存有用发现 | 也可能意味着搁置 |
| Waypost | 一个可以返回的位置 | 容易联想到导航 |
| Takebook | 像一本录音素材记录册 | 更直白，但个性较弱 |

视觉阶段比较了仅图形、仅文字、图形加文字三种形式。选定的 Logo 将规整字形与三条录音条目组合，每条在不同位置留有标记。

## 你会得到什么

交付内容取决于你请求的范围：

| 任务 | 交付物 |
| --- | --- |
| 应用图标 | 高分辨率母版、实际源文件格式、PNG 导出、所需尺寸版本，以及目标平台场景和小尺寸预览 |
| 命名 | 候选清单或选定名称、读音、含义、选择理由与取舍 |
| Logo | 可编辑矢量源文件、SVG 和 PNG 导出、适用的彩色／黑色／反白版本及使用说明 |
| 组合设计 | 应用名称与图标、名称与 Logo，或三者一起设计，并提供适用的共用视觉方向和使用建议 |

部分图标材质只能提供栅格源文件，需要原生平台图标包时请在需求中说明。候选清单和视觉试稿也可以单独交付。查看[案例文件](examples/notch/README.zh-CN.md#查看交付文件)或[完整工作流](skills/imprint/SKILL.md)。

## 常见问题

<details>
<summary>只有一个应用，可以直接做图标吗？</summary>

可以。说明应用用途、运行平台和希望传达的感觉即可，原型、截图或参考图都能帮助确定方向。已有名称可以保留，也可以一起命名；不需要先有公司品牌或单独的 Logo。

</details>

<details>
<summary>需要懂设计术语吗？</summary>

描述受众、希望传达的感觉和使用场景即可。方向未定时，Imprint 会提供具体选项：应用图标可以比较不同风格与主体，Logo 可以比较仅图形、仅文字和图文组合。它使用你的对话语言；命名时请说明目标语言和市场。

</details>

<details>
<summary>可以保留已有名称或 Logo 吗？</summary>

可以。说明哪些内容保持不变、哪些需要设计。新应用图标可以延续品牌特征，不必使用完全相同的图形。已经明确的选择会直接沿用。

</details>

<details>
<summary>可以让 agent 帮我决定吗？</summary>

可以，明确委托它代选即可。默认由你选择最终名称和视觉版本，也可以只做候选清单或视觉比较。请求推荐时，最终选择仍由你作出。

</details>

<details>
<summary>安装 skill 就包含图像生成能力吗？</summary>

Skill 提供工作流和设计指导，实际工具由 agent 环境提供。栅格概念需要图像生成能力，可编辑 Logo 需要矢量创建和渲染能力。开始视觉任务前，请确认环境具备相应工具。

</details>
