# Imprint

[English](README.md) | **简体中文**

一个用于设计产品名称、Logo 和应用图标的 skill。可以从零建立品牌，也可以单独完善已有品牌的某个部分。

## 安装

```bash
npx skills add Frost-96/imprint
```

也可以将 [`skills/imprint/`](skills/imprint/) 复制到你的 agent 的 skills 目录。

## 开始使用

告诉你的 agent 使用 Imprint，说明产品、受众和需要的交付物。有风格参考或希望保留的已有资产，也一并提供。

**完整品牌形象**

> 使用 Imprint，为一个乐队排练应用设计名称、Logo 和应用图标。希望它温暖、有活力。先让我选择名称和概念，再进行精修。

**只做命名**

> 使用 Imprint，为一个家庭共享烹饪日志命名。给出中文和英文候选，附上读音、含义和取舍。

**名称与应用图标**

> 使用 Imprint，为一个比较测试记录的 macOS 工具起名并设计应用图标，附上 Dock 场景与小尺寸预览。请自行选择并精修最合适的方向。

**为已有品牌设计应用图标**

> 使用 Imprint，为已有品牌设计 iOS 应用图标。保留现有名称和 Logo，以附件中的品牌资产作为参考。

**探索风格**

> 使用 Imprint，参考附件里的卡通风格，探索几个不同轮廓和表情的应用图标。

风格可以组合：一个角色既可以手绘，也可以用毛毡或像素表现。你可以提供参考图，也可以让 Imprint 根据产品推荐方向。

Imprint 会使用你的对话语言。你可以自己选择概念，也可以委托 agent 选定方向并完成精修。

## 工作方式

- **从产品出发。** 先明确受众、品牌性格和使用场景，再选择视觉方向。
- **先探索，再精修。** 比较不同概念，再完善选定方案。
- **按用途设计。** Logo 从黑白结构开始；应用图标通过形状、色彩与材质建立识别，并检查小尺寸和实际使用场景。
- **交付可用文件。** 核验源文件和导出，提供相应的使用建议。

命名、Logo 和应用图标可以单独或组合完成。除非你要求修改，已有名称和资产会保留。完整流程见 [SKILL.md](skills/imprint/SKILL.md)。

## 你会得到什么

根据你的需求，交付物可以包含：

- 品牌定位、性格与命名依据。
- 可编辑的 Logo、字标，以及彩色和黑白版本。
- 应用图标母版、导出、尺寸适配与场景预览。
- 配色、字体、留白和使用建议。

## 工具与范围

Imprint 提供设计流程；你的 agent 需要具备相应的图像生成、矢量编辑、文件访问与浏览能力。名称和图形检索属于初步筛查，不等于商标核准。
