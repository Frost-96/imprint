# Logo applications

Read for requested website, avatar, print, and other placements of an established logo. Inspect the supplied asset's actual role/version. Application identities use the [icon workflow](../icons/workflow.md), including when derived from an existing logo.

## Compact marks

For authorized compact variants, preserve the selected mark's defining features and strategy; inherited weaknesses do not authorize a redesign. Adjust simplification, stroke weight, openings, mass separation, scale, crop, optical center, foreground/background, and edge spacing together with placement.

Small structural differences can preserve apparent consistency better than exact downscaling. Keep canonical and optical sources distinct with assigned uses. For a cropped character, protect identifying features while allowing intentional profile/occlusion; derive the crop separately from the canonical silhouette.

## Placement and size studies

Use [asset verification](../asset-production.md#verify-actual-files) for rendered size studies and actual-size inspection. Test requested navigation, avatar, and favicon placements with established colors/backgrounds. Study sizes do not establish platform export requirements.

If reduction fails, adjust spacing, weight, or selective simplification; derive an optical variant where needed while retaining the identifying feature. Record assigned sizes and measured minimums, then compare compact/full variants for perceptual consistency. Keep unresolved required-use failures visible in the handoff.

For physical applications, check intended dimensions, reproduction method, and substrate/background. A screen preview does not verify embroidery, engraving, or print; disclose unperformed production tests.

## Website logo

Adapt symbol, wordmark, or lockup to actual background and available width/height. Tune proportions, clear space, alignment, and color without assuming an app tile. Test horizontal marks at realistic dimensions rather than squeezing them into squares. Recheck affected files and appearances after adaptation.
