# Logo directions and preference discovery

Read before logo concepts. Apply shared [User choices](../../SKILL.md#user-choices); use these form and construction dimensions independently of the icon style menu.

## Discover the user's direction

Inspect supplied references for lettering, contour, proportions, negative space, composition, color, and authored irregularity. Distinguish an asset to edit from a style reference and separate artwork from presentation effects.

### Choose the logo form with the user

Resolve form before sketches. If unspecified, ask: **“Would you like a symbol only, lettering only, a symbol with the name, or a comparison before choosing?”** Bundle this with consequential preference and usage questions.

| Choice | Visible result |
| --- | --- |
| Symbol only | A graphic without the full name |
| Lettering only | The name or agreed initials shaped into the logo |
| Symbol with name | Graphic and lettering in one composition |
| Compare before choosing | Actual sketches of relevant forms |

Reuse an explicit form choice, authorized comparison, or delegation. “Warm” or “minimal” describes style, not form; a reference settles form only when following its composition is agreed. Switching forms reopens this choice, including when the current concept fails.

For comparisons, render monochrome studies at comparable finish and intended-use sizes. Keep visual language and lettering quality comparable; label additional differences. Explain what the graphic adds and what lettering alone retains or loses. A weak symbol candidate does not prove that no symbol is needed. Obtain the concept choice before refinement.

### Establish the visual direction

Offer brief-specific options with visible differences, fit, and trade-offs under User choices. These may combine form and treatment, such as restrained lettering, a rhythmic abstract mark, or an expressive drawn subject. Use authorized monochrome trials when verbal descriptions are insufficient. Direction is an exploration hypothesis; subject details may remain open.

## Form, composition, and visual language

Use these dimensions internally, showing only consequential choices:

| Dimension | Decisions and guidance |
| --- | --- |
| Mark form | Full-name wordmark, initials, abstract relationship, or recognizable subject. Read [lettering](lettering.md), [figurative marks](figurative.md), or [abstract construction](workflow.md#monochrome-construction) accordingly. |
| Composition | Standalone mark, lockup, emblem/badge; horizontal or stacked as useful. Use [applications](applications.md) for actual placements. |
| Shape/edges | Geometric/organic, angular/rounded, block/line, regular/drawn; density and negative space |
| Lettering | Structure, width, weight, rhythm, case, and custom gestures appropriate to the selected script |
| Feeling/period | Translate mood into the visible choices above |
| Color intention | Fixed/preferred colors and background roles; resolve palette after monochrome construction |

A mascot is a figurative treatment; a badge is composition; negative space is a construction method. Combine dimensions where useful. Consider typography and abstraction alongside recognizable subjects: an animal name need not produce an animal mark. Justify a symbol's contribution when pairing it with lettering.

## Complete the direction brief

Record selected form/authorized comparison/delegation, desired impression, composition and reference cues, fixed constraints, intended uses, and open concept questions. Include identity-specific anti-patterns: plausible neighboring impressions or category shortcuts that would undermine the brief.

Return to the workflow when these decisions guide actual sketches while allowing meaningful alternatives.
