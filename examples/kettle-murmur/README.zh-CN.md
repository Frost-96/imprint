## 定位与名字

面向喜欢邀请朋友喝茶的人，提供日常散叶茶与小型品饮聚会。

一壶茶，给交谈留一点时间。

**Kettle Murmur**（建议读法：KET-uhl MUR-mer）。从合唱调整为壶边交谈；声音的比喻表达轻松陪伴。

品牌性格：好客：壶嘴与呼唤姿态；从容：宽松衬线字标；有一点古怪：鸟与壶共用轮廓。

避免：宫廷奢侈、冥想疗效承诺、通用茶叶嫩芽。

候选命名方向：相聚的声音：Kettle Choir / Table Chorus；日常停顿：Steep Hour / Little Interval；陪伴物件：Second Cupboard / Guest Kettle；复核后的替代方向：Kettle Murmur。

## 图形选择与精修

![三个实际绘制的黑白方向](exploration/concepts.png)

| 方向 | 关系 | 主要风险 |
| --- | --- | --- |
| A / 呼唤的茶壶 | 壶嘴是一只呼唤的鸟，提手构成尾部。 | 壶和鸟的双读需要简化。 |
| B / 三只杯，一张桌 | 三个不同高度的杯子汇到同一托盘。 | 容易变成茶具商店图标。 |
| C / 叶片的合唱 | 三片叶围成一个有缺口的旋转花冠。 | 叶片组合在茶品牌中较常见。 |

采用 **A**：呼唤的小鸟与茶壶共用轮廓，比杯子阵列更有人情味；代价是更偏亲切而非严肃茶器。

实际精修：初稿采用复合偶奇填充，提手和壶身重叠处出现意外白缝；改为提手在后、主体在前的独立路径。

## 使用与文件

- 主图形 / 字色 `#173E39`；浅底 `#F4EBCF`；强调色 `#D9AE3D`；辅助色 `#A6B6A2`。强调色用于色块或装饰，不能代替文字对比度检查。

- 字标字体：Fraunces 的固定轴实例 WallFraunces。字体文件、OFL 和来源见 [fonts](fonts/)。编辑文字版前安装随包字体；一般投放优先使用转曲版。

- 完整 Logo 建议画布宽度至少 **220 px**，图形独用建议 **32 px** 起；32/16 px 使用 `mark-small.svg`。尺寸按画布宽度计算，保持纵横比。

- 16 px 眼睛只作轮廓辅助，完整字标最低宽度按实际渲染建议使用。

- 保留 SVG 自带留白，外部再留至少图形宽度的 1/8；不要拉伸、增加阴影、描边或把细字压进头像。深底用白色 / 浅色反白版本。

- `sources/`：图文组合、独立字标、独立图形的彩色 / 黑 / 白 SVG，以及文字版字标与小尺寸图形。

- `exports/`：透明背景 PNG。16 px 文件是实际诊断样本，只有达到上面的建议尺寸才作为推荐用法。

- `previews/`：配色与反白展示、头像示意。头像示意不等同于平台上架图标包。

- `verification/`：实际尺寸图、源文件映射、渲染与导出一致性结果。
