## 定位与名字

为使用老相机的人提供检测、维修与维护课程；延长物件使用而非售卖怀旧滤镜。

让旧机器，继续结出新照片。

**Tin Orchard**（建议读法：tin OR-cherd）。金属与果园的反差连接机械维修和继续生长的比喻，适用于让旧相机继续使用。

品牌性格：机械感：圆形与接缝；有生命：一个斜出的叶片；可信赖：紧凑工具铭牌字标。

避免：完美翻新保证、现成相机轮廓、复古噪点遮盖结构。

候选命名方向：机器继续生长：Tin Orchard / Metal Bloom；修复后的光：Second Exposure / Light Again；工作台的秩序：Frame Bench / Small Shutter Works。

## 图形选择与精修

![三个实际绘制的黑白方向](exploration/concepts.png)

| 方向 | 关系 | 主要风险 |
| --- | --- | --- |
| A / 机械果实 | 一圈分段镜筒接上一片斜叶。 | 小尺寸分段容易聚成齿轮。 |
| B / 再次曝光 | 两个错位画框共有一个圆形焦点。 | 普通摄影图形，缺少名字性格。 |
| C / 维修印章 | 工具铭牌里嵌入 T 与开放圆环。 | 机械感清晰但缺少生命意象。 |

采用 **A**：机械圆环和叶片的反差能连接维修与继续使用，比画框更贴合 Tin Orchard。

实际精修：小尺寸去掉两侧细短接缝，保留外圈、方形内部结构和斜叶；避免读成带噪点的旧相机贴纸。

## 使用与文件

- 主图形 / 字色 `#183B79`；浅底 `#C9D2DD`；强调色 `#EB5B31`；辅助色 `#EDF0E7`。强调色用于色块或装饰，不能代替文字对比度检查。

- 字标字体：Barlow Condensed（随包名称 RangeBayward）。字体文件、OFL 和来源见 [fonts](fonts/)。编辑文字版前安装随包字体；一般投放优先使用转曲版。

- 完整 Logo 建议画布宽度至少 **200 px**，图形独用建议 **32 px** 起；32/16 px 使用 `mark-small.svg`。尺寸按画布宽度计算，保持纵横比。

- 16 px 内方孔较弱，32 px 以上更适合独立使用。

- 保留 SVG 自带留白，外部再留至少图形宽度的 1/8；不要拉伸、增加阴影、描边或把细字压进头像。深底用白色 / 浅色反白版本。

- `sources/`：图文组合、独立字标、独立图形的彩色 / 黑 / 白 SVG，以及文字版字标与小尺寸图形。

- `exports/`：透明背景 PNG。16 px 文件是实际诊断样本，只有达到上面的建议尺寸才作为推荐用法。

- `previews/`：配色与反白展示、头像示意。头像示意不等同于平台上架图标包。

- `verification/`：实际尺寸图、源文件映射、渲染与导出一致性结果。
