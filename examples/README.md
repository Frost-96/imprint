# Examples

**English** | [简体中文](README.zh-CN.md)

24 fictional brands, designed by running Imprint on different briefs. The names, audiences, products, and scenarios are invented; the artwork, editable files, and design iterations are actual outputs. Application images are illustrative mockups, including AI-generated imagery where noted.

## Featured studies

- [Puddlefolk](puddlefolk/README.md) — a nature journal, a frog character, and a simpler face for small icons.
- [Fault Lantern](fault-lantern/README.md) — a debugging tool with a lantern symbol and hand-drawn pixel lettering.
- [Swerve Assembly](swerve-assembly/README.md) — an electronic music identity built around slanted type and poster graphics.
- [Palm Silt](palm-silt/README.md) — a pottery identity with hand-drawn lettering and an irregular impression mark.

## Inside each case

Each folder contains a design rationale, concepts and refinements, editable SVG sources, PNG exports, previews, size checks, and the applicable font licenses. The seven earliest studies include application mockups; the other seventeen focus on naming and logo design. Deliverables and size recommendations vary by brief.

Core logo artwork uses vector paths and shapes. Raster imagery in application previews is identified in the case notes. Font-based wordmarks are distinguished from hand-drawn lettering.

Naming searches were preliminary and visual-conflict checks remain incomplete. These studies demonstrate the design process and files produced, without claiming trademark clearance, customer validation, or market results. Third-party fonts retain their accompanying licenses.
