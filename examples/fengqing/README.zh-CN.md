## 定位与名字

为愿意继续穿旧衣的人提供可见修补与小型缝补课程。

把修补留下来，把日常接着穿。

**缝晴**（建议读法：féng qíng）。用修补的缝与转晴的晴建立关系，表达衣服继续被穿着的明亮情绪。

品牌性格：耐心：线的回环；乐观：开放日轮；有手感：保留中文字的笔画节奏。

避免：全新无痕保证、过度乡村复古、针线交叉的工具图标。

候选命名方向：修补后的情绪：缝晴 / 衣然好；物的延续：续衣间 / 留衣；共同练习：针慢慢 / 补一会。

| 候选 | 选择理由 / 优点 | 代价 / 风险 |
| --- | --- | --- |
| 缝晴 | 两字短，缝补与晴朗形成设计意图 | 谐音风情，口头需要确认汉字 |

## 图形选择与精修

| 方向 | 关系 | 主要风险 |
| --- | --- | --- |
| A / 朝向日光的缝线 | 一根线穿过开放日轮并回成一个环。 | 线条小尺寸需要更粗。 |
| B / 可见的补丁 | 四角有短缝线的偏移补丁。 | 过于接近通用缝补服务图标。 |
| C / 相连的两片布 | 两片布的边界由三道桥接起来。 | 像道路或电子连接。 |

采用 **A**：开放日轮和回环线表达修补后的延续，比补丁图标更贴合名字的情绪。

实际精修：加粗主线，并将整个轮廓收进画布；最右光线与上方光线不再靠近裁切边缘。

## 使用与文件

- 主图形 / 字色 `#623747`；浅底 `#F4DDD9`；强调色 `#B76770`；辅助色 `#D8A44E`。强调色用于色块或装饰，不能代替文字对比度检查。

- 字标字体：站酷小薇体（ZCOOL XiaoWei）。字体文件、OFL 和来源见 [fonts](fonts/)。编辑文字版前安装随包字体；一般投放优先使用转曲版。

- 完整 Logo 建议画布宽度至少 **160 px**，图形独用建议 **32 px** 起；32/16 px 使用 `mark-small.svg`。尺寸按画布宽度计算，保持纵横比。

- 中文字标建议至少 160 px；复杂的缝字不压缩到小头像。

- 保留 SVG 自带留白，外部再留至少图形宽度的 1/8；不要拉伸、增加阴影、描边或把细字压进头像。深底用白色 / 浅色反白版本。

- `sources/`：图文组合、独立字标、独立图形的彩色 / 黑 / 白 SVG，以及文字版字标与小尺寸图形。

- `exports/`：透明背景 PNG。16 px 文件是实际诊断样本，只有达到上面的建议尺寸才作为推荐用法。

- `previews/`：配色与反白展示、头像示意。头像示意不等同于平台上架图标包。

- `verification/`：实际尺寸图、源文件映射、渲染与导出一致性结果。
