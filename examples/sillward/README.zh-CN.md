## 定位与名字

为个人业主改造既有住宅，通过采光与空间重新组织改善日常居住。

在已有的地方，留出更好的生活尺度。

**Sillward**（建议读法：SILL-werd）。以 sill 和方向性后缀组合的自造名称；意图是朝向窗边与日常空间，不声称已有词源。

品牌性格：审慎：留白与严格边界；空间感：门洞和偏移平面；安静：宽字距与单色基础。

避免：摩天楼剪影、虚构获奖背书、奢华地产金色。

候选命名方向：安定的土地：Still Acre / Quiet Plot；空间余量：Room Between / Extra Threshold；改造动作：Open Measure / Second Plan；复核后的替代方向：Sillward。

## 使用与文件

- 主图形 / 字色 `#303E39`；浅底 `#EAE6DD`；强调色 `#A8B39A`；辅助色 `#C8C6B9`。强调色用于色块或装饰，不能代替文字对比度检查。

- 字标字体：Manrope（随包名称 RangeBody）。字体文件、OFL 和来源见 [fonts](fonts/)。编辑文字版前安装随包字体；一般投放优先使用转曲版。

- 完整 Logo 建议画布宽度至少 **240 px**，图形独用建议 **16 px** 起；32/16 px 使用 `mark-small.svg`。尺寸按画布宽度计算，保持纵横比。

- 完整字标优先用于图纸标题与网站页头；图形独立出现时需要先建立品牌语境。

- 保留 SVG 自带留白，外部再留至少图形宽度的 1/8；不要拉伸、增加阴影、描边或把细字压进头像。深底用白色 / 浅色反白版本。

- `sources/`：图文组合、独立字标、独立图形的彩色 / 黑 / 白 SVG，以及文字版字标与小尺寸图形。

- `exports/`：透明背景 PNG。16 px 文件是实际诊断样本，只有达到上面的建议尺寸才作为推荐用法。

- `previews/`：配色与反白展示、头像示意。头像示意不等同于平台上架图标包。

- `verification/`：实际尺寸图、源文件映射、渲染与导出一致性结果。
