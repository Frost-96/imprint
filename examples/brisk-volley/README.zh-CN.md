## 定位与名字

面向成年初学者和下班后打球的人，组织水平匹配的羽毛球练习。

把下一拍打出去，不必先成为高手。

**Brisk Volley**（建议读法：brisk VOL-ee）。把轻快的节奏与来回击球放在一起，表达下班后也能加入的一场球。

品牌性格：有动势：倾斜和不等长端点；开放：明亮色块而非黑色竞技威慑；直接：粗壮大写字标。

避免：冠军或战绩虚构、攻击性猛兽、廉价速度拖影。

候选命名方向：击球动作：Brisk Volley / Next Rally；社交邀约：Court Company / Play After；轻盈节奏：Feather Tempo / Airbeat Club。

## 图形选择与精修

![三个实际绘制的黑白方向](exploration/concepts.png)

| 方向 | 关系 | 主要风险 |
| --- | --- | --- |
| A / 上扬的羽球 | 三片张开的羽片由一个斜向底托收拢。 | 孤立看可能像扇子。 |
| B / 下一次回球 | 一条折回的宽线表达来回一拍。 | 偏通用回转或金融图形。 |
| C / 开放的球场 | 场地边界与一颗离开边线的点。 | 较像地图入口。 |

采用 **A**：分开的羽片和底托带来明确的羽毛球语境；B 像通用回转符号，C 的场地图形太宽泛。

实际精修：保留羽片间的空隙和底托分离；没有为了制造迭代而给已清楚的轮廓增加装饰。

## 使用与文件

- 主图形 / 字色 `#192847`；浅底 `#E9F2FF`；强调色 `#FF6047`；辅助色 `#A7CBE9`。强调色用于色块或装饰，不能代替文字对比度检查。

- 字标字体：Barlow Condensed（随包名称 RangeBayward）。字体文件、OFL 和来源见 [fonts](fonts/)。编辑文字版前安装随包字体；一般投放优先使用转曲版。

- 完整 Logo 建议画布宽度至少 **220 px**，图形独用建议 **16 px** 起；32/16 px 使用 `mark-small.svg`。尺寸按画布宽度计算，保持纵横比。

- 不把标志理解为获奖、排名或职业竞技认证。

- 保留 SVG 自带留白，外部再留至少图形宽度的 1/8；不要拉伸、增加阴影、描边或把细字压进头像。深底用白色 / 浅色反白版本。

- `sources/`：图文组合、独立字标、独立图形的彩色 / 黑 / 白 SVG，以及文字版字标与小尺寸图形。

- `exports/`：透明背景 PNG。16 px 文件是实际诊断样本，只有达到上面的建议尺寸才作为推荐用法。

- `previews/`：配色与反白展示、头像示意。头像示意不等同于平台上架图标包。

- `verification/`：实际尺寸图、源文件映射、渲染与导出一致性结果。
