## 定位与命名

为街区和小型文化空间组织露天电影放映，重点是场所与共同观看。

把银幕带到有风的地方。

性格：轻盈：弯曲幕面；中文叙事：短句般的名字；开放：边界不封死。

避免：胶片齿孔、红毯奖杯、播放三角按钮。

命名领域：银幕与天气：风险是像旅宿；临时聚在一起：风险是像社交平台；离开影院：风险是名称太口语。

采用 **幕里风**，建议读法：mù lǐ fēng。幕面与风的关系适合露天放映

## 概念与精修

![三个黑白方向](exploration/concepts.png)

| 方向 | 可见关系 | 主要风险 |
| --- | --- | --- |
| A / 风中的银幕 | 一道有上下弯边的幕面被斜向内白打开。 | 也可能读成帆或旗。 |
| B / 共享前排 | 三个不等宽座位围着一道弧线。 | 像家具或剧院通用符号。 |
| C / 三个移动的画框 | 错开三道竖向边框表达连续观看。 | 更像书页或动态图形工具。 |

采用 **A**：弯曲的幕面把放映与风联系起来，比座位或胶片更贴合流动场所；旗帜或帆的阅读仍可能出现。

缩小外轮廓、增加边缘厚度，让上下曲线和两侧边框在缩小后连续。

## 使用与来源

- 主字色 `#2536A6`；浅底 `#E4E6FF`；强调色 `#A9B8F1`；辅助色 `#6679CD`。浅底用深色版，深底用反白版。

- 字标使用 站酷小薇体 / ZCOOL XiaoWei。这是许可字体的排字与转曲，不是原创字体；字体、OFL 和来源见 [fonts](fonts/)。文字编辑版需要安装随包字体。

- 完整 Logo 建议至少 **180 px 宽**，图形建议 **16 px 宽**起。图形 16 px 仍保留开口，中文完整 Logo 推荐 180 px 起；不把三个字挤入头像。

- 尺寸按画布宽度计算，保持纵横比。保留自带留白，外部再留至少图形宽度的 1/8；字标独用时外部留白至少大写字高的 1/2。不要拉伸、加阴影或挤压中文字。

- `sources/` 包含彩色 / 黑 / 白组合标志、转曲字标、图形，以及文字版字标和小尺寸图形；`exports/` 是透明 PNG；`previews/` 是成品与头像示意；`verification/` 是实际尺寸与检查结果。
